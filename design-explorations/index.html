Design Variants
Five standalone mockups of the same core screens — a beer log entry card, a friends' activity feed, and a log-entry form — each in a different visual direction. Click any card to open the full mockup.
Minimal · Mono
minimal-mono.html
Restrained Grayscale
Black, white, and mid-grays only. Heavy whitespace, 1px borders instead of shadows, type scale as the sole hierarchy tool. Calm and focused — content first.
Color Grayscale only
Density Low — lots of air
Best for Sober, long sessions
→
Minimal · Color
minimal-color.html
One Amber Accent
Same disciplined layout as mono, but a single amber/golden accent color for ratings, active states, and the "new log" badge. Everything else stays neutral. Warm without being loud.
Color Neutral + 1 amber
Density Low — clean
Best for Likely production v1
→
Maximal · Mono
maximal-mono.html
Dark Dashboard Energy
Dark background, giant type, inverted sections, dense information rows. All contrast comes from scale and layout — no color. Think editorial dashboard meets a beer-obsessive's Bloomberg terminal.
Color Black/white inverted
Density High — lots on screen
Best for Power users, stats nerds
→
Maximal · Color
maximal-color.html
Cheers Energy
Bold color blocking: forest green for the log panel, amber hero, coral for new-item alerts, purple for the feed header. High energy, expressive, and unmistakably "alive" — appropriate for a social drinking moment.
Color Multi-zone palette
Density High — expressive
Best for Mobile app / fun brand
→
